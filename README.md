# Art-Book

**Art-Book** is a curated collection showcasing a diverse range of artworks, aiming to provide inspiration and appreciation for art enthusiasts and creators alike.

## 🎨 Features

- **Diverse Art Collection**: A wide array of artworks spanning various styles and mediums.
- **Artist Spotlights**: Highlighting talented artists and their unique creations.
- **Regular Updates**: Continuously expanding the collection with new and exciting pieces.

## 🛠️ Technologies Used

- **HTML/CSS**: Structuring and styling the web pages.
- **JavaScript**: Enhancing interactivity and user experience.
- **GitHub Pages**: Hosting the project for easy access and sharing.

## 🚀 Getting Started

To view the Art-Book:

```bash
git clone https://github.com/AidenLM/Art-Book.git
cd Art-Book
```

Then open `index.html` in your browser.

Alternatively, visit the [GitHub Pages site](https://aidenlm.github.io/Art-Book/) to explore the collection online.

## 🤝 Contributing

Contributions are welcome! If you have artwork you'd like to add:

1. Fork the repository.
2. Add your artwork to the appropriate directory.
3. Update `index.html` to include your piece.
4. Submit a pull request with a brief description of your addition.
